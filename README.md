## 🎯 About

**How to Fish** is a fishing survival simulator where you explore, fish, and try to make your way home.

This repository contains a collection of mods and trainers designed to enhance the gameplay experience.

## ⚙️ Installation

### 1. Download

Download the latest archive from the **[Releases](https://github.com/max-m-hq2001c0/how-to-fish-mods/releases)** page.

### 3. Run

1. Run `HTF_ModInstaller.exe`.
2. Select the required mods.
3. Click **Apply**.
4. Launch **How to Fish**.

> ⚠️ **Note:** Modding tools can sometimes trigger antivirus warnings because they interact with game files.
